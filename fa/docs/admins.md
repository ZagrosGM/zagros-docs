# ادمین‌ها

زاگرس چند ادمین با سطحِ دسترسیِ متفاوت را پشتیبانی می‌کند، تا یک همکار یا
نماینده بتواند کاربرانِ خودش را مدیریت کند بدون اینکه کاربرانِ شما را ببیند.

## دو نوع

| نوع | می‌تواند |
|---|---|
| **sudo** | همه‌چیز: ادمین‌های دیگر، نودها، هسته‌ها، تنظیماتِ پورتال، تنظیماتِ شبکهٔ خودِ پنل |
| معمولی | کاربرانِ خودش، به‌علاوهٔ دقیقاً همان بخش‌هایی که ماتریسِ دسترسی‌اش (پایین) باز کرده — و آن هم در چارچوبِ محدودیت‌هایی که برایش گذاشته‌اید |

**مدیریتِ ادمین‌ها** (ساخت/حذف ادمین، ارتقا به sudo) همچنان فقط-sudo است.
بقیهٔ سطحِ زاگرس (`/api/zagros/*` — نودها، هسته‌ها، تنظیماتِ پورتال، قالب‌های
اشتراک، گواهی‌ها، اپلیکیشن‌ها) برای ادمینِ معمولی‌ای که ماتریسِ دسترسی‌اش اجازه
دهد باز است؛ به‌طور پیش‌فرض (بدون ماتریسِ ذخیره‌شده) ادمین معمولی همهٔ بخش‌ها
را دارد.

## ساختِ ادمین

در داشبورد زیرِ **Admins**، یا از میزبان:

```bash
sudo zagros advanced create-admin      # نام، فلگِ sudo و رمز را می‌پرسد
sudo zagros advanced reset-admin       # بازنشانیِ رمز
```

فیلدها:

| فیلد | معنا |
|---|---|
| نام‌کاربری / رمز | مشخّصاتِ ورود |
| is sudo | دسترسیِ کامل |
| بیشینهٔ کاربران | سقفِ تعدادِ کاربرانی که این ادمین می‌تواند داشته باشد (`0`/خالی یعنی نامحدود) |
| انقضا | تاریخی که پس از آن ادمین نمی‌تواند وارد شود یا چیزی مدیریت کند |
| سقفِ تخصیصِ ترافیک (گیگابایت) | سقفِ **جمعِ** سقفِ حجمِ کاربرانش |
| سقفِ مصرفِ ترافیک (گیگابایت) | سقفِ **جمعِ** مصرفِ همیشگیِ کاربرانش — با عبور از آن، همهٔ کاربرانش تعلیق می‌شوند |
| تلگرام / وب‌هوکِ دیسکورد | اعلان‌های این ادمین کجا برود |
| دسترسی‌ها | ماتریسِ دسترسیِ هر بخش + اینباندهای مجاز برای ادمین غیر-sudo (پایین). unset = همهٔ بخش‌ها، همهٔ اینباندها. |

## دسترسی‌ها

دسترسِ ادمین غیر-sudo یک سند است که هر وقت بخواهید از همان دیالوگ ویرایش
می‌شود:

* **بخش‌های پنل** — برای هر هجده بخش (`overview`، `users`، `templates`،
  `subscriptions`، `applications`، `nodes`، `cores`، `routing`، `outbounds`،
  `inbounds`، `hosts`، `dns`، `certificates`، `monitoring`، `statistics`،
  `support`، `settings`، `advanced`) یک سطح انتخاب می‌کنید:

  | سطح | ادمین می‌تواند |
  |---|---|
  | **مخفی** | اصلاً بخش را نبیند — از ناوبری حذف می‌شود و deeplink نمی‌پذیرد. |
  | **فقط مشاهده** | بخواند؛ هر نوشتن رد می‌شود (403). |
  | **مشاهده + ویرایش** | کامل استفاده کند. |

* **اینباندهای مجاز** — یا همهٔ اینباندها، یا یک لیست صریح از tagها. ادمین
  محدودشده در انتخابگرهای Users/Templates فقط همین‌ها را می‌بیند و API
  ساخت/ویرایشِ کاربری که چیزی بیرون از لیست نام ببرد را رد می‌کند (انتخابِ
  *خالی* — که یعنی «همه» — هم برای او رد می‌شود تا هیچ‌وقت به «همه‌چیز»
  ارتقا نتواند داد).

اعمالِ قانون در API است نه در رابط: داشبورد فقط چیزی را آینه می‌کند که سرور
از قبل اعمال می‌کند. ادمین sudo همیشه دسترسی کامل دارد و می‌تواند حسابِ sudoer
دیگر را ویرایش کند — از جمله تنزلش به معمولی. ادمین sudo نمی‌تواند **خودش**
را تنزل دهد (آخرین sudoer نباید همه را قفل کند)؛ این کار را از حساب sudo
دیگری یا `zagros-cli` بکنید.

اگر ادمین‌ها را با بات ارائه می‌دهید، [سند API](./api.md) را ببینید.

::: tip
این دو سقف به دو پرسشِ متفاوت جواب می‌دهند: *تخصیص* محدود می‌کند ادمین چقدر
می‌تواند **بفروشد**، *مصرف* محدود می‌کند کاربرانش چقدر می‌توانند **مصرف کنند**.
دومی از شما در برابر ادمینی محافظت می‌کند که کاربرانش ناگهان خیلی پرمصرف می‌شوند.
:::

## ادمینِ آغازین

`SUDO_USERNAME` و `SUDO_PASSWORD` در `.env` وقتی هیچ ادمینی وجود ندارد، یک ادمینِ
sudo می‌سازند. از آن برای ورودِ اول استفاده کنید، سپس یک ادمینِ واقعی بسازید و این
متغیّرها را بردارید — ماندنِ یک رمز در فایل روی دیسک یک ریسک است.

`zagros-cli admin import-from-env` این مشخّصات را وقتی می‌خواهید صریحاً وارد
می‌کند.

## نشست‌ها

توکنِ ادمین یک JWT است با عمرِ `JWT_ACCESS_TOKEN_EXPIRE_MINUTES` (پیش‌فرض ۱۴۴۰،
یعنی یک روز؛ `0` یعنی بی‌انقضا). با خروج یا انقضای توکن، داشبورد به صفحهٔ ورود
برمی‌گردد.

## مالکیت

هر کاربر یک مالک دارد. ادمینِ معمولی فقط کاربرانِ خودش را می‌بیند؛ ادمینِ sudo
همه را. این را API اعمال می‌کند نه رابط — ادمینِ معمولی که کاربرِ دیگری را بخواهد
۴۰۳ می‌گیرد، نه یک فهرستِ خالی که حقیقت را پنهان کند.

::: warning
حذفِ یک ادمین کاربرانش را حذف نمی‌کند: کاربران با پیکربندیِ سالم می‌مانند و برای
ادمینِ sudo دیده می‌شوند. اگر این را نمی‌خواهید، اول مالکیت را منتقل کنید.
:::
