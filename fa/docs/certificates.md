# گواهی‌نامه‌ها

زاگرس گواهی‌های TLS را برای دو چیزِ متفاوت مدیریت می‌کند:

| مصرف | کجا انتخاب می‌شود |
|---|---|
| خودِ **پنل** (HTTPS روی `UVICORN_PORT`) | `UVICORN_SSL_CERTFILE` / `UVICORN_SSL_KEYFILE` در `.env` |
| **شنوندهٔ اشتراک** (نشانی‌هایی که کاربران می‌گیرند) | *Subscriptions → TLS certificate* |

هر دو از یک انبارِ مدیریت‌شده می‌خوانند، پس گواهی‌ای که یک‌بار صادر شود در هر دو
جا قابل استفاده است.

## انبارِ مدیریت‌شده

گواهی‌ها زیرِ پوشهٔ داده (`/var/lib/zagros`) هستند و در داشبورد با همان چیزی که
مهم است فهرست می‌شوند: تاریخِ انقضا، اینکه کلیدِ خصوصی همراهش هست یا نه، و اینکه
گواهی نامی را که می‌خواهید پوشش می‌دهد یا نه.

* گواهی‌های **مدیریت‌شده** همان‌هایی هستند که زاگرس خودش صادر و تمدید می‌کند.
* گواهی‌هایی که خودتان وارد کرده‌اید هم فهرست می‌شوند، اما تمدیدشان با شماست.

## صدور

داشبورد ACME را برای شما پیش می‌برد. زاگرس تشخیص می‌دهد کدام کلاینتِ ACME روی
میزبان هست و همان را به‌کار می‌گیرد:

| تأمین‌کننده | شناخته‌شده به‌عنوان |
|---|---|
| `certbot` | certbot (EFF) |
| `acme.sh` | acme.sh |
| `lego` | lego (go-acme) |

اگر هیچ‌کدام نصب نباشد، رابط همین را می‌گوید به‌جای اینکه بعداً شکست بخورد.

::: warning
اعتبارسنجیِ HTTP-01 به **پورتِ ۸۰** نیاز دارد که آزاد و از اینترنت در دسترس باشد.
زاگرس پیش از شروع پورتِ ۸۰ را بررسی می‌کند و اگر چیزِ دیگری روی آن باشد می‌گوید —
برای همان یک دقیقه‌ای که صدور طول می‌کشد آن سرویس را متوقف کنید، یا با کلاینتِ
خودتان از مسیرِ DNS استفاده کنید.
:::

تمدید یک کارِ زمان‌بندی‌شده است، پس گواهیِ مدیریت‌شده پیش از انقضا بدون دخالتِ شما
تمدید می‌شود.

## گواهیِ wildcard

یک wildcard (`*.example.com`) با HTTP-01 صادر نمی‌شود — به DNS-01 نیاز دارد. اگر
لازم دارید، با کلاینتِ ACME دلخواهتان صادر کنید و به انبارِ مدیریت‌شده وارد کنید؛
[گواهیِ wildcard](../examples/wildcard-ssl.md) را ببینید.

## انتخاب برای پنل

```bash
sudo zagros env set TLS_MODE on
sudo zagros env set UVICORN_SSL_CERTFILE /var/lib/zagros/certs/live/example.com/fullchain.pem
sudo zagros env set UVICORN_SSL_KEYFILE  /var/lib/zagros/certs/live/example.com/privkey.pem
sudo zagros restart
sudo zagros status
```

پشتِ یک reverse proxy، `TLS_MODE` را خاموش (یا `auto`) بگذارید و بگذارید پروکسی
TLS را خاتمه دهد — پنل در آن حالت روی همان پورتی که انتخاب کرده‌اید HTTP ساده
می‌دهد.

## انتخاب برای لینک‌های اشتراک

در *Subscriptions*، زیرِ **TLS certificate** یک گواهیِ مدیریت‌شده را انتخاب کنید.
وقتی شنوندهٔ اشتراک از نوعِ `dedicated` با HTTPS باشد لازم است، و وقتی یک reverse
proxy خارجی TLS را برای شما خاتمه می‌دهد اختیاری است.

## انقضا بی‌صدا نیست

گواهی‌های نزدیک به انقضا در داشبورد و در `zagros doctor` نشان داده می‌شوند.
گواهی‌های مدیریت‌شده خودکار تمدید می‌شوند؛ برای گواهی‌های وارد‌شده، این هشدار
یادآورِ شماست.
