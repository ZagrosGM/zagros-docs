# نصب

## پیش‌نیازها

| نیاز | توضیح |
|---|---|
| یک سرور لینوکس | `x86_64` با دسترسیِ `root` یا `sudo` |
| Docker Engine و Docker Compose نسخهٔ ۲ | اگر نباشد، نصب‌کننده پیشنهادِ نصب می‌دهد |
| دیسک | هسته‌ها و داده‌هایشان زیر `/var/lib/zagros` است؛ چند گیگابایت کافی است |
| پورت‌های باز | جدولِ پایین |

| پورت | مالک | چه زمانی لازم است |
|---|---|---|
| `8000` | پنل (HTTP) و داشبورد | همیشه (قابل تغییر) |
| `80` | صدورِ گواهی (HTTP-01) و شنوندهٔ اشتراک | برای گواهیِ ACME یا شنوندهٔ اختصاصیِ اشتراک |
| `443` | پنل پشتِ TLS، شنوندهٔ اشتراک | برای TLS |
| `62050` | کنترل‌پلنِ نود (HTTPS امضا‌شده) | **روی نود**، در دسترس از پنل |
| `62051` | آغازین/اطلاعاتِ نود | **روی نود**، در دسترس از پنل |

## یک دستور

```bash
sudo bash -c "$(curl -fsSL \
  https://raw.githubusercontent.com/ZagrosGM/zagros-scripts/main/zagros.sh)" \
  -- install
```

گزینه‌ها:

| گزینه | اثر |
|---|---|
| `--database sqlite\|mysql\|mariadb\|postgresql` | انتخابِ پایگاه‌داده (پیش‌فرض: SQLite) |
| `--version <tag>` | پین‌کردنِ یک نسخهٔ مشخّص به‌جای تگِ شناورِ `latest` |

بدونِ `--version`، پنل با تگِ `latest` ایمیج اجرا می‌شود که هر انتشارِ **پایدار**
آن را جلو می‌برد — پس `sudo zagros update` بدونِ هیچ پین‌کردنی انتشارها را دنبال
می‌کند. `zagros status` و `zagros version` همیشه نشان می‌دهند `latest` روی سرورِ
شما در حالِ حاضر کدام نسخه است.

این اسکریپتِ آغازین عمداً لاغر است: خط‌فرمانِ مدیریتیِ همان نسخه را می‌گیرد و کار را
به آن می‌سپارد — پس همیشه همان CLI نصب می‌شود که به آن نسخه تعلق دارد.

## بعد از نصب چه دارید

| مسیر | محتوا |
|---|---|
| `/opt/zagros/` | `docker-compose.yml` و `.env` — خودِ استقرار |
| `/var/lib/zagros/` | پایگاه‌داده، هسته‌ها، گواهی‌ها، کلیدها، لاگ‌ها و پشتیبان‌ها |
| `/usr/local/bin/zagros` | خط‌فرمانِ مدیریتِ میزبان |

::: tip
`.env` تنها مرجعِ استقرار است. آن را با `zagros env edit` ویرایش کنید؛ در هر
`up` توسط compose خوانده می‌شود.
:::

## نخستین ورود

نصب‌کننده مشخّصاتِ نخستین ادمینِ sudo را چاپ می‌کند. اگر جا ماند:

```bash
sudo zagros advanced create-admin
```

سپس `http://<سرور-شما>:8000/dashboard/` را باز کنید. از اینجا صفحهٔ
[پیکربندی](./configuration.md) همهٔ متغیّرها را توضیح می‌دهد و صفحهٔ
[نودها](./nodes.md) روشِ افزودنِ سرور را.

## به‌روزرسانی

```bash
sudo zagros update                      # دنبال‌کردنِ تگِ شناورِ latest (انتشارهای پایدار)
sudo zagros update --version v1.0.0     # پین‌کردنِ یک نسخه
```

`update` معادلِ `docker compose pull` نیست: اول پشتیبان می‌گیرد، بعد ایمیج را
می‌کشد، migration را اجرا می‌کند و سلامت را بررسی می‌کند — و **اگر پنل سالم
برنگشت، خودکار برمی‌گردد**. برای بازگشتِ دستی:

```bash
sudo zagros advanced rollback            # نسخهٔ قبلی
sudo zagros advanced rollback --to
```

## بررسیِ نتیجه

```bash
sudo zagros status      # سرویس‌ها، ایمیج، سلامت و جدولِ هسته‌ها
sudo zagros doctor      # گزارشِ کامل: داکر، دیتابیس، هسته‌ها، پورت‌ها، DNS، رجیستری
sudo zagros health      # یک نگاهِ ترکیبی (در صورتِ ناسالمی خروجی ۱)
sudo zagros logs        # دنبال‌کردنِ لاگِ پنل
```

## حذف

```bash
sudo zagros advanced uninstall --yes
```

کانتینرها، ایمیج‌ها، داده‌ها و خودِ CLI را پاک می‌کند. اگر ممکن است داده‌ها را
بخواهید، اول پشتیبان بگیرید (`zagros backup`).
