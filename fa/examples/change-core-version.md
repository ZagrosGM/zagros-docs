# تغییر نسخهٔ هسته

هر هسته‌ای که درایورش نسخه‌ها را از مخزنِ بالادستیِ خودش کشف می‌کند، می‌تواند به
**هر نسخهٔ منتشرشده — بالاتر یا پایین‌تر — یا به تگی که خودتان می‌نویسید** پین شود.
تنظیمات، داده‌ها و اکانت‌ها می‌مانند.

## از داشبورد

1. تبِ **Cores** را باز کنید (روی پنل، یا در تبِ **Cores** یک نود).
2. **change version** را انتخاب کنید.
3. یک نسخه از فهرست برگزینید — نسخهٔ نصب‌شده علامت خورده — یا یک تگ بنویسید.

فهرست از مخزنِ بالادستیِ خودِ هسته می‌آید، پس همان کاتالوگی است که پروژه منتشر
می‌کند. هسته‌هایی که سیستم‌عامل نصب می‌کند به‌جای یک انتخاب‌گرِ خالی، دلیلش را
می‌گویند.

## از میزبان

```bash
sudo zagros cores                                  # نسخه‌های فعلی
sudo zagros cores update xray --version v26.6.1    # پین‌کردنِ یک نسخه
sudo zagros cores reload xray                      # راه‌اندازیِ دوبارهٔ همین هسته
sudo zagros status                                 # تأیید
```

## پایین‌آوردنِ نسخه

پین‌کردنِ یک نسخهٔ قدیمی‌تر همان عملیات است — از فهرست انتخابش کنید. زاگرس
«قدیمی‌تر» را خطا نمی‌بیند، چون نسخه‌ای که لازم دارید تصمیمی دربارهٔ استقرارِ
شماست، نه دربارهٔ پنل.

## چه چیزی می‌ماند

| می‌ماند | نکته |
|---|---|
| تنظیمات و پیکربندی | پس از تغییر دوباره اعمال می‌شود |
| داده‌ها و اکانت‌ها | کاربران دوباره ساخته نمی‌شوند؛ هسته به فهرستِ اکانتِ ذخیره‌شده همگرا می‌شود |
| وضعیتِ روشن/خاموشِ هسته | هسته‌ای که روشن بوده، روشن برمی‌گردد |

## اگر تغییر شکست خورد

```bash
sudo zagros logs                 # خطای خودِ درایور همان‌طور منتقل می‌شود
sudo zagros cores                # وضعیت و سلامتِ هر هسته
sudo zagros advanced sync        # اعمالِ دوبارهٔ همهٔ اکانت‌ها روی هسته‌ها
```

هسته‌ای که بالا نمی‌آید آن را روی کارتش گزارش می‌دهد، با لاگش — بدون نیاز به SSH.

::: tip
روی نود هم همین عملیات در دسترس است، اما نود با همگام‌سازی پیکربندی می‌شود: از تبِ
**Cores** نود استفاده کنید نه ویرایشِ فایل‌ها روی آن سرور، وگرنه همگام‌سازیِ بعدی
کارتان را بازنویسی می‌کند.
:::
