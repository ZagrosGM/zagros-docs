# مسدودسازیِ ترافیک با مسیریابی

قواعدِ مسیریابی تعیین می‌کنند ترافیکِ یک کاربر به کجا اجازه دارد برسد — مسدود‌کردنِ
دسته‌ای از مقصدها، فرستادنِ بخشی از ترافیک از یک خروجیِ دیگر، یا رها‌کردنِ همه‌چیز
همان‌طور که هست.

## قواعد کجا هستند

مسیریابی در بخشِ **Routing** تنظیم می‌شود و هسته‌هایی که پشتیبانی می‌کنند آن را
اعمال می‌کنند (Xray و sing-box). یک قاعده یک فهرستِ مرتّب است: نخستین تطبیق برنده
است، و هرچه با چیزی تطبیق نکند از خروجیِ پیش‌فرض می‌رود.

## شکل‌های رایج

**مسدود‌کردنِ یک دامنه**

```json
{"type": "field", "domain": ["geosite:category-ads"], "outboundTag": "block"}
```

**مسدود‌کردنِ یک بازهٔ شبکه**

```json
{"type": "field", "ip": ["10.0.0.0/8", "192.168.0.0/16"], "outboundTag": "block"}
```

**فرستادنِ ترافیکِ یک کشور از یک خروجیِ مشخّص**

```json
{"type": "field", "domain": ["geosite:google"], "outboundTag": "proxy-eu"}
```

**مسدود‌کردنِ یک پورت** (درخواستِ رایج روی سرورهای اشتراکی)

```json
{"type": "field", "port": "25", "network": "tcp", "outboundTag": "block"}
```

::: warning
قواعد به‌ازای هر اتصال ارزیابی می‌شوند، و «block» یعنی اتصال رد می‌شود — کلاینت
یک timeout می‌بیند، نه یک توضیح. اگر چیزی را مسدود می‌کنید که کاربر متوجهش
می‌شود، در یادداشتِ کاربر بنویسید.
:::

## اعمال و بررسی

```bash
sudo zagros cores reload xray        # اعمال روی هستهٔ در حال اجرا
sudo zagros status                   # هسته سالم برگشت؟
```

بعد از یک کلاینت تست کنید:

```bash
curl --socks5 127.0.0.1:1080 https://example.com   # باید مسدود شود
curl --socks5 127.0.0.1:1080 https://api.ipify.org # باید هنوز کار کند
```

## دام‌ها

| نشانه | علت |
|---|---|
| هیچ‌چیز مسدود نمی‌شود | یک قاعدهٔ بالاتر زودتر تطبیق کرده، یا هسته اصلاً مسیریابی ندارد |
| همه‌چیز مسدود می‌شود | قاعده‌تان خیلی گسترده است — یک قاعدهٔ خالی `{}` با همه‌چیز تطبیق می‌کند |
| هسته بعد از تغییر بالا نمی‌آید | قاعده به خروجی‌ای اشاره می‌کند که وجود ندارد؛ لاگِ هسته نامش را می‌گوید |

قواعد پیش از نوشته‌شدن اعتبارسنجی می‌شوند، پس یک قاعدهٔ غلط از نظرِ نحوی هرگز به
هسته نمی‌رسد — اما قاعده‌ای که معتبر و در عین حال خیلی گسترده است، همچنان تصمیمِ
شماست.
