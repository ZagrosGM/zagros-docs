# پشتیبان‌گیری و بازگردانی

یک پشتیبان یک آرشیو است که همهٔ چیزهایی را دارد که نبودشان اذیتتان می‌کند:
پایگاه‌داده‌ها، پیکربندی، گواهی‌ها، کلیدها و داده‌های هسته‌ها.

## گرفتنِ پشتیبان

```bash
sudo zagros backup            # مسیرِ آرشیو را چاپ می‌کند
sudo zagros backup --logs     # لاگ‌ها را هم می‌آورد
```

آرشیوها در `/var/lib/zagros/backups` می‌نشینند.

::: tip
`zagros update` پیش از هر تغییر پشتیبان می‌گیرد، پس حتا به‌روزرسانی‌ای که برنامه‌اش
را نداشتید هم پوشش دارد. با این حال پیش از یک جهشِ بزرگ خودتان هم بگیرید.
:::

## بازگردانی

```bash
sudo zagros restore latest
sudo zagros restore /var/lib/zagros/backups/zagros-backup-2026-08-30.tar.gz
sudo zagros status
```

بازگردانی **کلِ پنل** است: برای برگرداندنِ یک استقرار است، نه وارد‌کردنِ یک کاربر.
برای جابه‌جاییِ یک کاربر بین دو پنل از [API](./../docs/api.md) استفاده کنید.

## فقط فایل‌های سیستمی

وقتی استقرار را می‌خواهید بدونِ داده (تا همان چیدمان را روی یک میزبانِ تازه پس از
بازگردانیِ پایگاه‌داده در جای دیگر بسازید):

```bash
sudo zagros advanced backup-service
```

## نظافت

```bash
sudo zagros advanced clean --keep 7     # نگه‌داشتنِ ۷ آرشیوِ آخر
sudo zagros advanced prune              # ایمیج‌های داکر و تگ‌های منسوخ
```

## بُردنِ آرشیوها بیرون از سرور

پشتیبانی که روی همان دیسکِ داده باشد، در برابرِ خرابیِ دیسک پشتیبان نیست.

```bash
rsync -av /var/lib/zagros/backups/ user@storage:/backups/zagros/
```

## مطمئن شدن که پشتیبان واقعی است

آرشیوی که تاکنون بازنگردانده‌اید یک فرضیه است:

```bash
tar -tzf /var/lib/zagros/backups/<archive>.tar.gz | head
```

بهتر: یک‌بار روی یک میزبانِ موقت بازگردانید و بررسی کنید `zagros status` سالم
برمی‌گردد. همین یک تمرین است که به آرشیو ارزش می‌دهد.

## داخلِ آرشیو چیست

| محتوا | چرا مهم است |
|---|---|
| پایگاه‌دادهٔ پلتفرم و قدیمی | کاربران، ادمین‌ها، تنظیمات، نودها |
| `.env` و فایلِ compose | خودِ استقرار — بدون آن داده شکلی ندارد |
| گواهی‌ها و کلیدها | از دست‌رفتنشان یعنی صدورِ دوباره، و گواهیِ پین‌شدهٔ نود عوض می‌شود |
| داده و پیکربندیِ هسته‌ها | تا هسته همان‌طور که بود برگردد، نه مثل یک نصبِ تازه |
